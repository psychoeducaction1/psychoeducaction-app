# Isolation du parcours professionnel

Les comptes non actives conservent le menu historique, les commentaires directement visibles et la deconnexion Supabase habituelle. La fiche operationnelle s'affiche immediatement pendant la verification facultative du module clinique; un compte autorise conserve sa redirection clinique.

990 limite le refus pour lien clinique manquant aux professionnels effectivement actives. Les rencontres cliniques existantes restent protegees, meme si le professionnel est ensuite desactive. Aucune ligne metier n'est modifiee.

Toute future modification du parcours professionnel exige la seconde validation explicite du perimetre prevue dans AGENTS.md.
